# Codex 新手使用指南

本指南帮助你快速上手 Codex，用自然语言完成编程任务。不需要任何编程基础。

## 基本设定

### 语言
- 请始终使用中文与我交流，包括代码注释、文件名说明、提交信息等
- 如果我偶尔切换到其他语言，你也应保持用中文回复

### 称呼
- 称呼用户为「你」，保持友好自然的语气
- 你（Codex）在对话中提到自己时，直接用「我」
- 不要使用「作为 AI 模型」「作为一个语言模型」之类的开场白

### 沟通风格
- 回答要简洁明了，避免不必要的长篇解释
- 遇到不确定的需求，先问清楚再动手
- 完成任务后简要说明做了什么、改了哪些文件

## 怎么给 Codex 下任务

### 好的提问方式
```
帮我创建一个 Python 爬虫，抓取某个网页的标题
```
```
帮我把这个文件夹里所有 .txt 文件合并成一个
```
```
帮我看看这个代码为什么报错，然后修复它
```

### 不太好的提问方式
```
写个爬虫
```
（太模糊，Codex 不知道你要爬什么）

```
帮我做一个完整的电商网站
```
（范围太大，建议先拆成小步骤）

## 常见任务示例

| 你想做的事 | 可以这样说 |
|-----------|-----------|
| 创建新项目 | 帮我创建一个xxx项目 |
| 修改文件 | 帮我修改xxx文件中的xxx |
| 运行脚本 | 帮我运行xxx脚本 |
| 解释代码 | 解释一下xxx文件的作用 |
| 修复错误 | 帮我看看为什么报错，然后修复 |
| 添加功能 | 帮我给xxx添加xxx功能 |
| 格式化代码 | 帮我把这个文件格式化一下 |
| 写文档 | 帮我给这个项目写个说明文档 |

## 新手建议

1. **从小任务开始** — 先让 Codex 做一件小事，确认没问题后再继续
2. **描述要具体** — 告诉 Codex 你想要什么结果，而不是只说关键词
3. **不要害怕出错** — 改错了可以告诉 Codex 撤销
4. **多问** — 不确定的时候可以问 Codex「这样做安全吗」或「有什么建议」
5. **逐步推进** — 复杂项目拆成多步，每步确认后再继续

## 安全提示

- 不要把密码、API Key 等敏感信息直接写在代码里
- 删除文件前让 Codex 先确认
- 不认识的东西不要随便删
